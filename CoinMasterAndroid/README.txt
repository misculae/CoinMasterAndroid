COIN MASTER CONTOR - PROIECT ANDROID (PROTOTIP)

Acesta este un proiect-sursă Android Studio, NU un APK instalabil.

Ce conține acum:
- interfața pentru telefon;
- contoare pentru rotiri, atacuri, raiduri și fantome;
- butoane START, PAUZĂ și RESET.

Ce NU este încă implementat:
- capturarea ecranului Coin Master;
- detectarea finalului unei rotiri;
- recunoașterea automată a celor 3 simboluri identice din rândul din mijloc;
- afișarea unui contor flotant peste joc.

Regulile de detectare care trebuie implementate:
- fiecare rotire completă = +1 rotire, indiferent de simboluri;
- +1 atac doar la 3 ciocane pe rândul din mijloc;
- +1 raid doar la 3 porci pe rândul din mijloc;
- +1 fantome doar la 3 fantome albastre pe rândul din mijloc;
- 1 sau 2 simboluri speciale nu cresc contoarele de evenimente.

Pentru a deschide: Android Studio > Open > selectează folderul CoinMasterAndroid.
Pentru a construi APK: Build > Build Bundle(s) / APK(s) > Build APK(s).

Nu instala acest prototip ca și cum ar avea deja recunoaștere automată; aceasta este etapa următoare.
